# GitPractice3

Учебный Android-проект для практической работы №3.

Цель: освоить локальные репозитории, коммиты, ветвление и слияние Git.

## Запуск
Открыть папку в Android Studio с установленным Android SDK 35.
Система сборки: Gradle (версии Android Gradle Plugin 8.7.3).

Примечание: Gradle Wrapper в архив не включён; Android Studio может предложить установить Gradle. Для готовой автономной сборки требуется сгенерировать wrapper в установленном Gradle.
